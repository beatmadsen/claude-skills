Hand-drawn architecture sketch of agent-tome, a Ruby gem where an AI agent keeps what it finds out. One call: the agent pipes JSON into the agent-tome command, which checks it, runs one command in one transaction against a SQLite file and prints JSON back; there is no server. How an article grows: create writes the first entry and addend adds more; nothing is ever updated or deleted. Consolidate writes a new article with one merged entry that takes over the old id, so the id still works, while the old article keeps its entries under a fresh id, linked to the new one. Who decides what a search finds: the Search command keeps only the keywords the tome knows, after lower-casing them and making the last word singular, then returns articles with any of them, most matches first, or with --match all only articles that have every word asked for, so one word the tome has never seen gives no results. Field names are from the code; the example ids and words are illustrative.
